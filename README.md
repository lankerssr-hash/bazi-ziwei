# 八字 · 紫微 协同分析

一个本地跑的命理排盘与解读工具。两个独立模块放在同一个界面里，
可以各自分析，也可以交叉比对。

> ⚠️ **先说清楚**：这是一个关于命理文化的工具，不是预测软件。
> 里面的判断来自传统命理典籍的规则和语言模型的生成，
> 没有科学证据支持。请当成一种文化阅读和自省的镜子，
> 不要用它做医疗、婚姻、投资之类的实际决定。

## 它有什么

### 两个模块

| | 八字（子平） | 紫微斗数 |
|---|---|---|
| 排盘 | 四柱、藏干、十神、纳音、大运、流年 | 十二宫、十四主星、辅星、杂曜、十二神 |
| 分析 | 格局、旺衰、调候、神煞、喜忌 | 星曜庙旺、三方四正、四化飞星 |
| 分项 | 总评 性格 事业 财运 感情 配偶 颜值 健康 大运 | 命格 事业 财帛 感情 相貌 大限 流年 |
| 交互 | 点分项按钮出解读 | **点任意一个宫格，单独解那个宫** |

### 三个跨模块功能

- **交叉分析**：把八字和紫微两份盘一起给模型，
  要求它只输出「两套都指向同一方向」的和「两套说法冲突并解释为什么」，
  而不是各说一遍再拼起来。
- **合盘**：两个人对比。十层判定 ——
  日干、夫妻宫、年支、年柱天合地合/天克地冲、年柱纳音、阴阳配、
  五行互补、用神互补、克夫克妻、四柱地支整体。
  带「我是谁」开关，选了就全文用「我／对方」说话。
- **视角**：站在一个人的角度，看他眼里的另一个人是怎样的。
  依据是「对方的日干在视角人眼里是什么十神」＋「视角人的配偶星在对方盘里旺不旺」
  ＋「两人夫妻宫的关系」。第一人称输出。

### 知识库

- `classics.py` —— 滴天髓、穷通宝鉴、渊海子平、子平真诠的节选与检索
- `tiaohou.py` —— 调候用神表、神煞、纳音、日柱断语、空亡、流年
- `mangpai.py` —— 盲派案例检索（按四柱干支匹配相似命例）
- `xiang.py` —— **盲派取象**：把八字映射到「具体干什么」。
  例如「时上带印主门店」→ 适合开店；
  「财落门户」→ 开门做买卖；「印主技术」→ 有一技之长。
  每条规则都在注释里标了原文出处。
- `sihua.py` —— 紫微四化飞星（十天干四化、各宫飞出飞入、自化）

## 怎么跑

### 1. 装依赖

```bash
pip install -r requirements.txt
```

`PySide6` 是界面，`lunar_python` 管农历节气，`izthon` 是紫微排盘。
（`pymupdf` 和 `rapidocr_onnxruntime` 只给两个开发工具用——
`pdfread.py` 和 `pdf2text.py`，用来把扫描版书变成文字。不装也能跑主程序。）

### 2. 配一个模型

程序走 OpenAI 兼容接口。有两种配法：

**方式一：环境变量**（推荐）

```bash
export DS_PROXY_KEY=sk-你的密钥
```

**方式二：文件**

在项目目录下建 `deepseek_key.txt`，里面只放密钥。
或者在 `ai_config.json` 里把 `provider` 改成 `doubao` / `custom`，
再填对应的 `url` 和 `model`。

默认上游是 `http://127.0.0.1:8787/v1/chat/completions`（本机转发站）。
你可以改成本地转发，也可以直接指向任何 OpenAI 兼容的服务。

### 3. 启动

```bash
python app.py
```

## 一个设计上的选择

**「拒绝电报体」是硬性要求。**

所有提示词最前面都会前置一段规则，要求
**每一处逗号、句号、分号之间的汉字不得少于五个**，
并且在拿到结果后自动检查，超标就带着更狠的提醒重跑一次。

这不是洁癖。传统命理书里那种「水多，印重，土空」的写法，
对外行来说等于没写——不知道在说什么，也不知道该做什么。
这个工具的目标是**把术语翻译成人话**：

> ✗ 「日主甲木，月令卯木，月刃格，喜火忌水。」
>
> ✓ 「她是甲木日主，生在卯月，等于一棵树长在了最旺的节气里，
> 这叫月刃格，说白了是自身能量很足、有股冲劲。
> 喜火，意思是越主动输出、越折腾越顺。」
